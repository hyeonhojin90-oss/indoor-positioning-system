# 자료·측위 구현 재검토 — 2026-09-09

이번 작업은 자료 목록·기존 분석·지도 제약·Android 수집 코드 검토다. 엔진과 지도는 수정하지 않았다. GLB 전체를 새로 렌더링해 모든 출입구를 측정하거나 PDF를 재판독한 결과는 아니다.

## 사용자 확정사항

- 2층 기둥 왼쪽과 오른쪽 모두 책상공간 진입 가능. 자유공간/M-space와 오른쪽 진입구 설명·사진은 이미 제공됨. 반복 요청하지 않는다.
- 2층 증축부는 긴 직선 통로. 사진 끝 이후 계단은 존재하지만 사용자가 일단 미반영 요청. 막다른 벽으로 확정하지 않는다.
- 3층도 긴 직선 증축부와 넓은 연결 공간이 있으며 최신 스캔 이미지 제공됨. 2층의 계단 미반영 지시를 3층의 동일 구조 확정으로 확대하지 않는다.

## 이미 있는 근거와 반영 누락

- `indoor/web/assets/3f/it_3f_right_wing.glb`: 실파일 17,755,992 bytes, glTF2, 6 meshes, accessor bbox 39.822×7.382×53.039. 메타데이터는 기존 분석과 일치. bbox는 복도 실측 길이가 아니다.
- `indoor/web/assets/3f/it_3f_spatial_report.pdf` 존재. 기존 `indoor/docs/archive/3F_REBUILD_ANALYSIS.md`에 개방부 약6.121m, 신규공간 약25.317×6.964m, IT홀 계단 폭 약2.422m와 정합 기준점 기록. 수치의 원자료 재대조 필요, 사용자 재측정 요청은 후순위.
- `indoor/tools/glb-viewer/assets`에 4층 코어·양쪽 복도 원본 및 mono, 평면 이미지 존재. mono는 독립 스캔 증거가 아니다.
- `indoor/docs/archive/4F_REBUILD_BRIEF.md`에 화장실 통로 폭1.262m, 출입구 폭0.902m와 계단실 보고서 치수 기록. 전체 미확인으로 설명한 것은 부정확하다.
- Documents/Downloads 파일명 검색에서 2층으로 식별되는 GLB는 찾지 못함. scan.glb의 촬영 범위는 아직 식별하지 않았으므로 2층 GLB가 없다고 단정하지 않는다. 기존 사용자 스캔 이미지는 확보돼 있다.
- `areas-v1.json`: 2층 main→study 기둥 왼쪽 연결 누락. study 끝 y682와 main 시작 y700 사이 간격이 남음. 통행 가능 확인과 좌표 추출 완료를 구분해야 한다.
- 3층 entry/free/extension/IT홀 영역·6개 포털은 이미 존재하나 diagram-derived/provisional로 남음. GLB가 자동으로 엔진에 연결되는 구조가 아니다.
- 4~10층은 별도 영역 추가 없이 common 메인복도·코어·계단입구 사용. 화장실/끝방 통로 수집 랩과 실제 지도 연결은 별개다.

## 우선 개선

1. 자료 경로→관측 사실→도면 좌표→측위 영역/포털→검증 상태를 한 표로 관리. CURRENT_STATUS와 체크리스트의 오래된 설치·지원 범위 설명 정리.
2. corridorMotion의 main_right/main_left 및 수평 x축 하드코딩을 영역별 중심선·접선·폭으로 일반화. 2·3층 extension 직선에도 같은 완화 적용, 열린 연결 공간에서는 다중 후보 유지.
3. Android 보정 수집에 기존/OFF/ON 동시 실행·기록 연결. 현재 기존 PDR만 표시하며 별도 새 엔진 화면은 Expo의 3종 동시 비교와 다르다.
4. Android 역방향 points.reversed() 수정: 시작 라벨과 랩 목록 계약을 정하고 중복 시작점 제거·원래 출발점 마지막 랩 포함 검증. 화면 배치만으로 완료 처리하지 않는다.
5. 미확인 영역은 막힌 벽과 구분하되 무제한 정상 추적처럼 표시하지 않는다. unknown 체류·후보 분산·복구 상태를 표시하고 근거 없는 점프를 감지한다.
6. 성능은 평균 랩 오차 외 중앙값/95백분위, 오분기율, unknown 시간 비율, 복구 시간, 층 오판을 기록. 튜닝한 4회 재생은 독립 검증 아님. 날짜/회차 단위 분리 평가.
7. 자기장 OFF는 패턴 시퀀스 OFF인지 전체 자기장 OFF인지 명시. Runtime은 시퀀스 OFF에서도 자기장 구역 관측을 사용하므로 명칭을 혼동하지 않는다. 패턴 개선은 직진/분기 반복과 기기별 평가 후 결정.
8. 앱에 engine/map/model/build 버전과 세션 ID를 함께 기록·표시. Expo 접속 주소는 현재 네트워크에서 생성하고 서버 응답과 휴대폰 실제 진입 검증을 구분.

## 추가 자료 판단

2·3층 전체 재촬영은 현재 필요하다고 판단하지 않는다. 먼저 GLB 정합·문/기둥/통로 추출을 수행해야 한다. 이후 스캔 사각지대, 이동식 가구의 현재 배치, GLB 장거리 축척 검증용 소수 실측, 독립 보행 검증만 구체적으로 요청한다. 오류·불확실 라벨은 자동 학습에 편입하지 않는다.
