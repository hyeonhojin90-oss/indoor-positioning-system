## 문제점

- 2D 메인 경로 그래프와 PDR 기능은 아직 모든 층에 동일하게 확장되지 않았다.
- 일부 층 치수는 현장 실측이 아닌 피난안내도 비례를 사용한 초안이다.
- AR 안내와 실제 휴대폰 센서 융합은 아직 구현 전이다.
- T-Beam 실제 환경과 정식 GPS 데이터셋이 없어 보정 방식은 미확정이다.
- 건물 공유기와 휴대폰의 Wi-Fi RTT 지원 여부를 확인하지 않았다.
- 실외 휴대폰 GPS에서 실내 측위로 전환하는 조건은 현장 실험 전이다.
