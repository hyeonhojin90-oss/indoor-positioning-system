# 프로젝트 개요

## 목표

교내 셔틀과 건물 내부 이동을 연결하여 사용자가 목적 강의실까지 이동할 수 있는 안내 시스템을 제작한다.

## 현재 범위

- IT융합대학 1~10층 2D·3D 지도
- 강의실 검색과 층별 구조 확인
- PDR, 자기장 지문, 지도 정합 실험
- GPS 원시 데이터 수집 기반 구축
- 향후 Android/iOS AR 길 안내 앱을 위한 지도 데이터 준비

## 범위 밖

- 현재 단계의 앱스토어 배포
- 검증되지 않은 센서 값의 실제 위치 서비스 적용
- 피난안내도만을 근거로 한 임의의 건축 치수 확정
