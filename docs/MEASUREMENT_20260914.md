1. 보정 데이터 수집 → 경로 라벨 비교 → 4층 → 코어 출구에서 오른쪽 계단 입구 경로.
2. 정방향 평상시: 코어 출구 → 오른쪽 계단 입구.
3. 역방향 평상시: 오른쪽 계단 입구 → 코어 출구.
