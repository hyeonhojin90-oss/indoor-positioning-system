## 현재 구현 수준

- 지도: 사용자 확인한 IT융합대학 1~10층 2D·3D는 현재 단계 완료로 취급한다. 지도 렌더링 완료와 모든 공간의 측위 그래프 완료는 다르다.
- Android: 강의실 안내 / 2D·3D 지도 / 보정 수집 유지. 1~4층 메인복도 최소 PDR·정합, 1~10층 경로/랩 수집, 기압 시험, 다중 센서+AP 구역 수집 소스가 있다.
- Expo: 실내측위 시험 / 보정 데이터 수집. 시작 위치 후보 확인 또는 수동 기준점, 자유 이동 시험, 경로/랩·다중 센서 구역 수집이 있다. 현재 App.js의 SCHEMA_VERSION은 5이며 원시 과거 데이터의 schema 3/4와 구분한다.
- AP 수집: Android 구역 수집에서 스캔 시작/수동 요청으로 기록. 일반 위치 추적에 AP 구역 분류·자동 복구가 통합됐다는 뜻이 아니다. iOS 주변 AP 미지원은 AP 0개 관측과 구분한다.
- Expo floorTracking.js: 초기 5개 기압 중앙값, 최근 3개 중앙값, 0.44 hPa/층, 같은 후보 3회 확인. 아직 시간 기반 수직 이동 상태 머신이 아니다.
- 기존 문서에 과거 구현 전 상태·schema·AP 제거 설명이 남아 있다. 현재 상태와 실제 소스, 날짜별 WORKLOG를 우선하며 과거 문장을 새 검증으로 해석하지 않는다.

## 합의한 개선 방향과 아직 제안인 사항

- FIND3의 지문 라벨 분류 개념을 참고해 구역 판별과 구역 내 이동 추적을 분리하고 관측을 상호 결합한다. 모든 강의실을 별도 학습 클래스로 만드는 방식은 우선하지 않는다.
- 강의실 앞 후보는 추적된 위치 분포와 공용 지도 출입문/노드의 대응으로 표시한다. 층을 처음부터 하나로 확정하지 않고 복수 층·구역 후보를 유지한다.
- 개인 기본 보폭 + 경량 회귀 보정에 사용자가 동의했다. Ridge, 초기 ±20% 출력 제한은 실험 제안이며 학습·성능 검증 전이다. 빈도가 빠르다고 보폭을 무조건 늘리지 않고 과검출도 따로 평가한다.
- PrettyIndoor는 설계 참고. 파티클·그래프/영역 제약, 자기장 시퀀스, 센서 품질 가중치, 상대기압 수직 상태 머신, 앵커 자동 복구는 새 통합 엔진으로 아직 미구현이다.
- 구역 점수와 파티클 가중치에 같은 관측을 중복 반영하지 않는다. 점수/예시 임계값을 보정된 정답 확률로 표현하지 않는다.
- 주요 앵커는 1층 정문, 각 층 좌우 사이드계단 입구, 코어·메인복도 교차영역. 교차점은 폭을 가지며 모든 통과를 중앙 한 점에 강제 스냅하지 않는다. 엘리베이터 지원에는 별도 연결 노드가 필요하다.
- 경로 추천과 위치 추적 제약을 분리한다. 좁은 복도는 폭 있는 영역/선분, 개방공간은 2D 이동 영역, 문은 연결부로 표현한다. 확인된 벽만 강한 제약으로 사용하고 미확인 영역으로 이동한 후보를 전부 삭제하지 않는다.
- 최근 연구 중 센서 품질·공간 의미 기반 융합, 중간 랩 기반 오프라인 궤적 smoothing을 우선 검토한다. 추정 라벨을 독립 정답으로 평가하지 않으며 회차·날짜·기기 분리 평가를 수행한다.

참고: FIND3 https://github.com/schollz/find3 (MIT), PrettyIndoor https://github.com/wnlab-isti/PrettyIndoor (이전 검토에서 명시 라이선스 확인 못 함; 직접 복사하지 않고 개념 재구현), IPIN 2024 희소 라벨 궤적 보정 https://doi.org/10.1109/IPIN62893.2024.10786186, 2025 의미 지도 융합 https://doi.org/10.1016/j.measurement.2024.115874. 논문의 결과를 우리 건물 성능으로 전용하지 않는다.

## 2·3층 현장 설명: 다음 작업에서 반드시 유지

- 2층 메인복도→2107 자유공간→M-space 연결 가능.
- 2107과 ㄷ자 책상공간 사이에는 벽이 있어 직접 이동 불가. 메인복도로 나와 다른 진입구를 이용한다.
- 기둥·TDM 옆 파란 굵은선 진입구에서 책상공간 또는 증축부 복도로 들어간다. 증축부 복도 양옆에 2105/2104 강의실이 있다.
- 핑크선은 대표 동선, 굵은 파란선은 사용자 표시 진입구다. 표시의 픽셀 폭을 실제 통로 폭으로 확정하지 않는다. 이미지 전체를 길찾기 데이터로 반영한 상태는 아니다.
- 3층은 기존 GLB/지도와 IT홀·증축부 측정 자료를 먼저 대조한다. IT홀 계단은 3층 내부 높이차를 가진 경로로 모델링하며 임의 4층 전환 금지.
- 2·3층 실제 이동 가능한 곳을 잘못 막지 않는다는 보장은 현재 없다. 통행 가능 영역/출입구/확정 벽/미확인 구간을 지도에 먼저 표시하고 검증한 다음 측위 제약을 적용한다.
