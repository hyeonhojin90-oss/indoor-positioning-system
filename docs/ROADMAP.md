## Wi-Fi RTT 및 일반 AP 지문

- [x] RTT 단말 지원 1차 확인: Galaxy Tab SM-X216N 미지원, 별도 Android 휴대폰 지원 확인
- [x] 지원 휴대폰에서 현장 AP 스캔: 해당 관측의 AP 12개 중 RTT responder 0개 (2026-08-29)
- [x] 현 단계 측위 입력에서 RTT 거리측정을 제외하고 PDR·자기장·지도·상대기압 중심으로 진행
- [x] Android 보정 수집에 일반 AP BSSID·RSSI와 다중 센서 기록 구현
- [ ] 일반 AP 지문으로 코어·강의실 라인·계단 구역 구분 가능성 검증

RTT 지원 환경의 **1차 확인은 완료**다. 건물 전체 AP 미지원으로 확정한 것은 아니며 실제 거리측정(ranging)은 수행되지 않았다. 건물 전역 조사와 RTT 재검토는 새로운 지원 AP 근거가 생겼을 때의 선택 작업이며 현재 개발의 선행 조건이 아니다. 일반 AP RSSI 지문은 RTT 거리측정과 별개다.
