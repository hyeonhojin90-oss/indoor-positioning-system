# 작업 기록

## 2026-08-29 — 루트 README 현행화

- 초기 계획 중심의 프로젝트 설명을 현재 구현 상태에 맞게 개정했다.
- 실외 GPS, 실내 PDR·자기장, 2D·3D 지도와 향후 모바일 앱의 역할을 구분했다.
- 실외 안내를 버스 T-Beam 위치 추적과 정류장 이후 휴대폰 GPS 안내로 분리했다.
- 휴대폰 GPS에서 실내 PDR 기반 안내로 전환되는 전체 이동 흐름을 추가했다.
- Wi-Fi RTT는 장비·건물 환경 지원 여부를 확인하기 전인 후보 기술로 기록했다.
- 모바일 앱은 Windows 개발 환경을 고려해 Android 우선, iOS 후속 검토로 정리했다.
- 완료된 지도 기반과 아직 실험·구현 전인 센서 융합·앱 작업을 분리해 기록했다.
- 현재 우선순위를 지도 검수, GPS 실험, PDR·자기장 보정, 앱·AR 통합 순서로 갱신했다.
