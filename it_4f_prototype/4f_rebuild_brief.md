# IT융합대학 4층 클레이 3D 재구성 브리프

작성일: 2026-08-16

## 1. 작업 목적

4층 LiDAR 스캔 원본을 그대로 합치는 것이 아니라, 피난안내도, 현장 사진, LiDAR 평면도, GLB 스캔, 자기장 측정값을 참고하여 안내용으로 깔끔한 클레이형 3D 지도를 다시 만든다.

최종 지도는 다음 기능을 지원해야 한다.

- 엘레베이터 허브에서 출발
- 메인 복도 진입
- 목적 강의실까지 경로 표시
- 강의실 번호 표시 토글
- 계단/엘레베이터 구분
- PDR/자기장 보정 위치 표시 확장 가능

## 2. 제공된 자료 정리

### 2.1 피난안내도 사진

사용자가 제공한 1~4층 피난안내도 사진 중 4층 피난안내도가 4층 구조의 1차 기준이다.

4층 피난안내도에서 확인된 점:

- 전체 구조는 사용자가 말한 것처럼 위에서 보면 `ㅗ`에 가깝다.
- 메인 복도는 긴 가로축이다.
- 엘레베이터/계단 허브는 메인 복도에서 아래쪽으로 내려오는 줄기처럼 붙어 있다.
- 엘레베이터 허브 주변에 계단과 엘레베이터가 있고, 이 둘의 좌우 위치가 현재 모델에서 반대로 들어간 것으로 보인다.

## 3. 현재 모델의 문제점

현재 `clay.html` / `src/clay4f.js` 클레이 모델은 다음 문제가 있다.

1. 엘레베이터/계단 허브는 추가됐지만 실제 `ㅗ` 구조가 완전히 맞지 않다.
2. 계단과 엘레베이터의 좌우 위치가 반대로 들어간 것으로 보인다.
3. 현재 화면 기준에서 왼쪽/오른쪽 복도 방향 자체는 맞지만, 방 배치가 반대로 들어갔다.
4. 4213의 방향이 잘못 표시됨.
   - 사용자의 최신 지적: 4213은 오른쪽으로 가야 나오는 곳.
   - 4213은 건물 안쪽에 있는 느낌.
5. 엘레베이터에 가까운 쪽은 4218 강의실이다.
6. 바깥쪽으로 갈수록 4210 등이 나오는 구조로 이해해야 한다.
7. 현재 모델은 4213과 4218, 4210의 상대 위치가 반대로 들어간 가능성이 높다.

## 4. 최신 구조 이해

사용자의 최신 설명을 기준으로 다음처럼 이해한다.

### 4.1 전체 형태

위에서 본 4층 구조는 `ㅜ`가 아니라 `ㅗ`이다.

즉:

- 긴 가로 복도 = 메인 복도
- 엘레베이터/계단 허브 = 메인 복도에서 아래쪽으로 붙은 세로 줄기
- 사용자는 엘레베이터 허브에서 나와 메인 복도에 진입한 뒤 좌우 중 하나로 이동한다.

### 4.2 방향 기준

현재 3D 화면 기준:

- 화면 왼쪽 = 엘레베이터 기준 왼쪽 방향
- 화면 오른쪽 = 엘레베이터 기준 오른쪽 방향

다만 정문 기준 건물 좌우와는 반대로 느껴질 수 있으므로, 안내문은 항상 다음 형식으로 쓴다.

- 엘레베이터에서 내려 왼쪽
- 엘레베이터에서 내려 오른쪽

### 4.3 방 배치 수정 가설

최신 사용자 지적 기준:

- 4213은 오른쪽으로 가야 나오는 곳.
- 4213은 건물 안쪽에 있는 쪽.
- 엘레베이터에 가까운 쪽은 4218.
- 바깥쪽은 4210 쪽.

따라서 기존 데이터에서 단순히 `4213~4204 = 왼쪽`, `4218~4228 = 오른쪽`으로 둔 것은 재검토해야 한다.

다음 작업 전 확인 필요:

- 4213, 4218, 4210이 각각 엘레베이터 기준 어느 방향에 있는지 최종 확정
- 4120~4128이 메인 복도 아래쪽 어느 구간에 붙는지 최종 확정
- 계단과 엘레베이터의 좌우 위치 최종 확정

- 목적지는 빨간색 강조.
- 현재 위치는 초록색.
- 경로는 노란색/주황색 선.

기능:

- 목적지까지 경로 표시
