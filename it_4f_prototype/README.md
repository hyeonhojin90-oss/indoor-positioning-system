# IT융합대학 4층 PDR + 자기장 프로토타입

4층부터 실내 위치 보정 알고리즘을 만들기 위한 초안입니다.

## 포함된 것

- `data/it_4f_map.json`: 4층 복도, 강의실, 계단/엘레베이터, 자기장 fingerprint 기준점
- `index.html`: 브라우저에서 보는 4층 단순 지도 및 알고리즘 테스트 UI
- `src/app.js`: PDR 이동, 자기장 fingerprint 비교, 복도 스냅 보정
- `src/styles.css`: 화면 스타일

## 현재 알고리즘

1. 4층 엘레베이터 앞을 시작점으로 둔다.
2. 사용자의 걸음 수와 방향으로 PDR 위치를 계산한다.
3. 현재 자기장 Total 값을 사전 fingerprint와 비교한다.
4. 가장 가까운 fingerprint 지점을 후보로 잡는다.
5. PDR 위치와 자기장 후보 위치를 가중 평균해 복도 위 위치로 보정한다.

## 다음 측정이 필요한 지점

- 4F_EV_FRONT: 4층 엘레베이터 앞
- 4F_4213: 4213 앞
- 4F_4210: 4210 앞
- 4F_4218: 4218 앞
- 4F_4120: 4120 앞
- 4F_4225: 4225 앞

각 지점에서 X/Y/Z/Total을 5~10초 정도 기록하고 평균/표준편차를 넣으면 됩니다.
