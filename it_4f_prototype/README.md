# IT융합대학 3F/4F 실내 길찾기 프로토타입

중앙 코어 복도를 출발 기준점으로 삼아 3층과 4층 목적지를 안내하는 실내 위치 보정 프로토타입입니다.

## 포함된 것

- `data/it_4f_map.json`: 4층 복도, 강의실, 계단/엘레베이터, 자기장 fingerprint 기준점
- `data/it_3f_map.json`: 3층 강의실과 증축부 구조 오버라이드
- `index.html`: 3층/4층 2D 지도
- `clay.html`: 3층/4층 통합 3D 구조 확인
- `pdr.html`: 3F/4F 경로, 수동 PDR, 자기장 보정, 휴대폰 센서 테스트
- `src/pdr.js`: 층별 복도 그래프, 경로 계산, 센서/수동 PDR, 자기장 보정

## 현재 알고리즘

1. 3층 또는 4층 중앙 코어 복도를 시작점으로 둔다.
2. 사용자의 걸음 수와 방향, 또는 휴대폰 모션/방향 센서로 PDR 좌표를 계산한다.
3. PDR 좌표를 메인 복도·코어 복도·3층 증축부 복도 그래프에 스냅한다.
4. 다른 층 목적지는 중앙 메인계단의 12계단 + 중간참 + 12계단 연결로 안내한다.
5. 4층에서는 자기장 Total을 현장 fingerprint와 비교해 PDR 좌표를 가중 보정한다.
6. 3층 자기장 fingerprint는 아직 측정 전이므로, 값이 쌓이기 전에는 보정을 적용하지 않는다.

## 다음 측정이 필요한 지점

- 3F 중앙 코어 복도와 3층 증축부 입구
- 4F_EV_FRONT: 4층 엘레베이터 앞
- 4F_4213: 4213 앞
- 4F_4210: 4210 앞
- 4F_4218: 4218 앞
- 4F_4120: 4120 앞
- 4F_4225: 4225 앞

각 지점에서 X/Y/Z/Total을 5~10초 정도 기록하고 평균/표준편차를 넣으면 됩니다.
