# GPS Test Results

이 문서는 실제 GPS 테스트 결과를 시간순으로 누적한다.

## 현재 결과 상태

- 정식 T-Beam GPS 실험 결과 없음
- `firmware/uno-raw-test`의 UNO·NEO-7M 원시 수신 스케치만 보존됨
- GPS 정확도와 보정 성능은 아직 검증되지 않음

실험하지 않은 값을 추정해 채우지 않고 `미측정`, `미확인` 또는 `해당 없음`으로 기록한다.
