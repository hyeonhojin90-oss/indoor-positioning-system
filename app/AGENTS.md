# 모바일 앱 작업 지침

- 웹 지도와 중복된 층 데이터를 새로 만들지 않고 공용 데이터 인터페이스를 사용한다.
- Windows 환경에서 Android를 먼저 개발하고 실제 기기에서 지도·센서·AR 핵심 기능을 검증한다.
- iOS는 개발·빌드·배포 조건과 센서·AR 지원 범위를 확인한 뒤 확장한다.
- 버스 T-Beam 위치와 하차 후 사용자 휴대폰 GPS 위치를 같은 측위 주체로 취급하지 않는다.
- 실외·실내 전환 조건은 현장 실험 전까지 임의로 확정하지 않는다.
- 센서 권한 거부, AR 미지원 기기, 추적 손실 시 2D 지도 대체 화면을 제공한다.
- 실내 위치는 단일 센서 값으로 확정하지 않고 PDR·자기장·지도 정합·기준점을 융합한다.
- Wi-Fi RTT는 장비와 건물 환경 지원 여부를 검증하기 전에는 필수 기술로 구현하지 않는다.
