# 실내측위·센서 수집 앱

현재 Android Studio 소스는 [android-native](android-native/README.md)에 있다. 공용 indoor/web 지도와 PDR·파티클 엔진을 재사용하며 경로 라벨·센서 기준점 수집, 지도 표시와 실내 안내 실험을 포함한다. Expo 앱은 이전 수집·재생 비교 자료다. android-updates는 수정·검증 기록이다. 버전별 구현과 현장 검증 상태는 [현재 상태](../docs/CURRENT_STATUS.md)와 [합의 대조](../docs/INDOOR_AGREEMENT_AUDIT_20261002.md)를 따른다.
