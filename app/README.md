# 모바일 앱 영역

셔틀 위치부터 목적 강의실까지 연속 안내하는 모바일 앱을 위한 영역이다. Windows 개발 환경을 고려해 Android를 먼저 구현하고, 실제 기기 검증 후 iOS 지원 범위를 검토한다.

현재 앱은 구현 전이다. 기술 스택과 웹 지도 데이터를 재사용할 공용 인터페이스를 확정한 뒤 소스 구조를 생성한다.

예정 기능:

- 강의실 검색과 경로 안내
- 버스 T-Beam 위치와 하차 후 사용자 휴대폰 GPS 안내 연결
- 실외 휴대폰 GPS에서 실내 측위로 전환
- PDR·자기장·지도 정합 기반 실내 위치 보정
- 기압계 기반 층 변화 보조 판정
- 카메라 기반 AR 화살표 안내
- AR 미지원 상황의 2D 지도 대체 안내

Wi-Fi RTT는 공유기와 휴대폰 지원 환경을 확인하기 전인 후보 기술이며 기본 기능으로 확정하지 않는다.
