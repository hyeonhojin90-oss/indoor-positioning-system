현재 사용자 앱 흐름:

- 강의실 번호나 공간 이름을 검색하고 결과를 선택한다.
- 앱이 목적지 층, 좌·우 메인복도 경로와 시작 기준점을 자동으로 선택한다.
- 1층은 `정문·메인복도 진입점`, 2~4층은 해당 층 `코어복도 출구 중앙점`에서 시작한다.
- 목적지 방향을 보고 방향을 보정한 뒤 안내를 시작하면 걸음 센서와 회전벡터로 PDR을 갱신하고 메인복도 중심선에 정합한다.
- 현재 정합 위치, 가까운 강의실과 목적지까지 남은 지도상 거리를 표시한다.
- Wi-Fi RTT 거리측정은 제거 상태를 유지한다. 일반 안내의 AP는 등록 기준점 진입 시 한 번 요청하고, 새 결과를 지문과 비교해 PDR 15m 안에서만 모드 4 파티클을 약하게 재가중한다. 단일 스캔은 강제 복구를 허용하지 않는다. `보정 수집`에서는 학교 AP의 BSSID·RSSI 지문을 자기장과 함께 저장하기 위해 Wi-Fi·위치 권한을 사용한다. 활동 인식은 걸음 센서에, 인터넷 권한은 Three.js 기반 3D 지도 로드에 사용한다.
- 상단에서 `강의실 안내`, `2D·3D 지도`, `보정 수집` 모드를 분리해 제공한다. 지도 모드는 목적지 선택 없이 1~10층을 볼 수 있고, 보정 수집은 미완료 층의 기존 경로·중간 랩 JSONL 수집을 유지한다.
- 과거 절대기압표 자동 추정과 기준층 이후 상대 층 추적 시험은 일반 안내가 아니라 센서 보정 기능이므로 `보정 수집` 모드에 배치한다.
- 기압계 층 추적 시험에서 현재 층을 한 번 입력해 기준 기압을 저장하면 `0.44 hPa/층`으로 상대 층을 계산하고, 같은 후보가 3회 연속 관측될 때 현재 층을 갱신한다.
- 입력 없는 실험 모드는 과거 현장 기준표(1층 `998.59 hPa`~10층 `994.53 hPa`)와 현재 기압을 직접 비교해 가장 가까운 층 후보를 표시한다. 날씨 보정이 없으므로 기준 기압 차이를 함께 표시하며 위치 판정에는 사용하지 않는다.
- `다중 센서+AP+BLE 구역 기준점 수집`은 층과 물리 기준선을 선택해 시작한다. 왼쪽 계단은 입구 정면까지, 오른쪽 계단 내부는 출입문 통과 후 첫 계단참 중앙에서 측정한다. 일반 강의실 라인은 `4204 문 정면 · 복도 중앙선` 형식의 세부 위치가 필수다. 가속도·자이로·걸음·자기장·기압·방향과 BLE는 연속 기록하고 AP는 시작 시와 `새 AP 스캔 요청`을 누를 때 저장한다. 첫 요청 뒤 다음 요청까지 30초 카운터와 요청 후 경과시간, 마지막 응답 시간, 새 결과·이전 결과 횟수와 마지막 새 결과 경과시간이 표시된다. 카운터가 끝나기 전과 결과 대기 중에는 요청 버튼이 비활성화된다. `fresh_results=true`인 새 결과만 AP 지문 후보로 센다. 새 구역 출력은 `Downloads/IndoorPositioning`의 schema 7 JSONL이며 `zone_id`를 포함하고 RTT 값은 없다. 이전 schema 4/5 구역 자료, 자유 추적 schema 6과 일반 경로 schema 3은 보존한다.

기존 현장 수집 방식과 자료:

- 측정 1회에 복도 전체를 연속 기록한다.
- 1~10층을 선택할 수 있다. 2~10층은 `코어복도 출구 중앙점→오른쪽/왼쪽 계단 입구` 경로를 제공하고, 1층은 정문 시작 경로를 제공한다.
- 경로의 중간 랩 순서는 공용 `floor-XX.json`에서 메인복도 x좌표를 읽어 코어에서 계단 방향으로 자동 생성한다. 별도 증축부처럼 메인복도 x좌표가 없는 공간은 이 좌·우 복도 수집 경로에서 제외한다.
- 왼쪽 메인복도는 위쪽 행을 우선 사용한다. 오른쪽 메인복도는 2~5층에서 아래쪽 행을 사용하고 6~10층은 위쪽 행을 우선 사용한다. 6~10층 아래쪽 행은 후속 반복 측정으로 추가한다.
- 본동 메인복도와 동선이 다른 공간은 별도 경로로 수집한다. 현재 1층 본동·행정실 사이 야외복도, 2층 증축부, 3층 증축부·IT홀 계단, 5층 야외공간 프리셋을 제공한다. 2층 2107과 책상공간은 별도 경로를 쓰지 않는다.
- 아래 경로·랩은 기존 데이터셋 해석과 현재 `보정 수집` 모드에서 사용한다.
- 공용 지도에서 `provisional=true`인 현장 명칭·구조 미확정 공간은 자동 수집 경로에서 제외한다.
- 보존된 로그는 저장소 `indoor/data/raw`로 옮기고 `indoor/tools/analyze_positioning_logs.py`로 PDR·자기장·기압·지도 정합을 오프라인 재생한다.
- 1층은 다른 층의 코어 시작 방식을 사용하지 않는다. `정문 바깥 중앙 기준점→정문 출입문→정문·메인복도 진입점` 이후 정문 시점 기준 왼쪽·오른쪽 복도 중 하나를 선택한다. 정문 기준 왼쪽은 `1213→1210→1209→1204`, 오른쪽은 `1119→1122→1125→1128`이며 사이드계단 진입은 현재 제외한다.
- 1층 본동·행정실 사이 야외복도는 실내 복도와 별도 측정한다. `정문 출입문 앞`에서 시작해 `본동·행정실 사이 야외복도 입구→행정실 문→야외복도 중앙→야외복도 끝`을 차례로 랩 기록하며, `1213–1210` 사이 출입문은 이 경로에 포함하지 않는다.

1~4층 최소 실시간 측위 시험:

- 검색한 강의실의 지도 x좌표를 기준으로 층과 좌·우 메인복도 경로를 자동 선택한다.
- 1층은 `정문·메인복도 진입점`, 2~4층은 `코어복도 출구 중앙점`에서 위치를 초기화한다.
- 목적지 방향을 바라보고 방향 보정한 뒤 정합을 시작하면, Android 걸음 센서와 회전벡터로 상대 위치를 갱신하고 메인복도 중심선에 투영한다.
- 기존 현장 로그의 경로별 총 걸음 수로 임시 지도 보폭을 사용하며, 현재 정합 좌표와 가장 가까운 강의실 후보를 표시한다.
- 현재 단계는 검색 목적지와 알려진 시작점을 전제로 한다. 자기장 실시간 보정, 기압 자동 층 판정, 계단·엘리베이터·특수공간 정합은 후속 단계다.

예정 기능:

- 5~10층과 특수공간 강의실 검색·경로 안내 확장
- 버스 T-Beam 위치와 하차 후 사용자 휴대폰 GPS 안내 연결
- 실외 휴대폰 GPS에서 실내 측위로 전환
- PDR·자기장·지도 정합 기반 실내 위치 보정
- 기압계 층 변화 판정의 실제 엘리베이터·계단 검증과 장기 기압 드리프트 보정
- 카메라 기반 AR 화살표 안내
- AR 미지원 상황의 2D 지도 대체 안내

Wi-Fi RTT는 현 단계 실내 측위 입력에서 제외한다. 일반 Wi-Fi AP 지문은 `보정 수집`에서 강의실 라인·계단 구역을 구분할 수 있는지 검증하는 실험 입력으로만 다시 사용한다.
