# 5층 보정 기준점 사용 가능성

2026-09-18. 사용자가 5119를 명시적으로 확인했다. 16:09 이후 5개는 사용자가 '5층이 맞는듯'이라고 답한 잠정 5층 자료다. 실제 이동 순서와 앱 층 선택이 남았던 원인은 확정하지 않는다. 원본은 보존한다.

## 판정

5209는 Wi-Fi 기반 보정 실험의 우선 후보다. 코어와 5119는 보조 후보, 왼쪽 계단은 약한 확인용, 오른쪽 계단 내부는 짧아 보정 평가를 보류한다. 엔진에 적용하지 않았다. 미터 단위 오차 감소는 아직 평가하지 않았다.

| 기준점 | 새 Wi-Fi 스캔 | Wi-Fi 분리 시험 | BLE 5초 구간 |
|---|---:|---|---|
| 오른쪽 계단 내부 | 1 | 반복 검증 불가 | 8.27초로 분리된 5초 질의/참조 확보 불가 |
| 5209 | 3 | 3/3 자신의 지점 선택 | 22구간 중 21 일치, 1 판정 불가 |
| 코어 | 2 | 2/2 자신의 지점 선택 | 8구간 중 7 일치, 1은 5119로 혼동 |
| 5119 | 1 | 반복 검증 불가 | 5구간 모두 일치 |
| 왼쪽 계단 앞 | 1 | 반복 검증 불가 | 5구간 중 4 일치, 1은 5119로 혼동 |

5209 Wi-Fi는 스캔 하나를 제외하고 나머지를 참조로 만들었을 때 공통 AP RSSI 절대차 중앙값이 1~1.5dB다. 다른 지점 중 가장 비슷한 후보도 10.5~13dB로 차이가 있다. 전체 지문끼리 비교하면 5209–코어는 17dB(공통 AP 31개), 5209–5119는 24dB(16개)다. 반면 5119–왼쪽 계단은 Wi-Fi와 BLE 모두 2dB이며 공통 ID는 각각 16개, 7개다. 이 수치는 거리나 위치 오차가 아니다.

## 방법과 한계

- 실행: `node indoor/tools/evaluate_f5_radio.cjs`; 상세 수치는 report.json.
- Wi-Fi는 fresh_results만 사용하고 자기 세션의 질의 스캔을 참조에서 제외했다.
- BLE는 시간 전반/후반을 나누고, 5초 질의를 반대편 절반의 참조와 비교했다. 절반 경계를 가로지르는 질의는 제외했다. 질의 ID는 2회 이상, 참조 ID는 3회 이상 관측된 것만 사용했다.
- 공통 ID 5개 이상인 후보의 RSSI 절대차 중앙값으로 비교했다. 미검출 ID 패널티는 없으므로 신호 세기만의 탐색적 기준이다. 공통 ID 부족으로 탈락한 후보가 많아 전체 분류 성능으로 볼 수 없다. 5209는 22구간 중 10개에서만 다른 후보가 비교 조건을 만족했다. 코어는 8개, 5119는 5개, 왼쪽 계단은 3개다.
- 질의와 자기 참조 원시 관측은 겹치지 않지만 같은 정지 세션이다. 서로 다른 날·보행·휴대 방향·사람에 대한 독립 검증은 아니다. 동일 지점 반복 안정성과 넓게 떨어진 기준점 구분의 예비 근거다.
- 5209 주변의 인접 강의실 지문이 없어 '5209 문 앞 몇 m'인지 구분하는 능력은 알 수 없다. BLE 송신기가 고정 시설인지도 미확인이다.

## 적용 실험 방향

PDR의 복도 진행을 유지하고 전파는 가까운 후보 구간의 가중치를 조절한다. 단일 관측으로 기준점 좌표에 강제로 옮기지 않는다. Wi-Fi와 연속 BLE가 함께 지지할 때 보정하고, 신호 부족·후보 간 차이가 작을 때 보류한다. 저장된 정지 신호만으로 실제 보행 PDR 보정 전후 오차는 계산할 수 없다. 기존 기준점을 사용한 보정 ON/OFF 보행 실험이 다음 검증이다.
