## 공동 판단

현재 동일 파티클에 센서별 가중치를 순차 반영하는 것도 센서 융합이다. 별도 공동 점수가 없어서 융합이 전혀 없다는 해석은 틀리다. 다만 각 관측 뒤 재표본화, 서로 다른 시각, 겹치는 창, 후보 제거 때문에 공동 갱신과 항상 동일하지 않다.

권장: 센서별 지문 비교는 유지하고 최종 기준점 보정은 동일 후보 위치를 기준으로 함께 판단한다. 센서별 신선도, 반복 관측, 날짜 재현성, 후보 점수 여유에 따라 기여도를 바꾼다. 결측은 반대표가 아니며 AP 수백 개와 BLE 몇 개를 그대로 더하지 않는다. AP와 BLE 환경, 중첩 시간창의 상관 때문에 단순 독립 투표·확률 곱으로 과신하지 않는다. 자기장 격자와 V2 같은 자료는 중복 가중하지 않는다. 이미 순차 반영한 같은 관측을 공동 점수로 다시 반영해서도 안 된다.

## BLE 문턱 진단

운영 지문의 최소 공통 ID 조건과 입력창 최소 ID 조건을 5/3/2개로 바꿔 비교했다. 나머지 5초 창, 3초 평가, 송신기별 창 내 최소 2관측, RSSI 점수식은 동일하다.

|---|---:|---:|---:|---:|---:|
|5|0|0|0|0|0|
|3|18|16|2|9|8|

문턱3은 왼쪽 계단을 main_left로 2창 오판했고 문턱2는 코어를 왼쪽 계단으로 1창 오판했다. 오른쪽 계단은 모두 판정불가다. 중첩창이며 독립 정확도나 실제 위치오차 개선 시험이 아니다. 보행 중간 실측 정답도 없으므로 판정 증가를 성공으로 세지 않는다.

직전 6/6은 세션 전체 RSSI 중앙값과 최소 공통2개의 분석기 결과다. 현재 운영의 5초 창·최소5개·공통률 페널티와 다르므로 실시간 성공률로 사용할 수 없다.

판단: 최소5개는 이번 환경에서 지나치게 많은 증거를 버린다. 3~4개도 약한 증거로 받되, AP·자기장·지도 후보와 함께 제한적으로 사용하도록 시험한다. 2개 신호만으로 위치복구하지 않는다. 12m 게이트와 15% 후보량 완화는 분류가 통과한 뒤의 별도 실험이며 현재 0회의 첫 원인은 아니다.

## AP 현재 연결

- 경로 라벨: 자동 AP 요청 없음.
- 자유 위치 추적(FusionExperiment): BLE 시작만 있으며 AP 스캐너가 없다. JS도 ap_enabled=false. Wi-Fi 수신 분기가 있어도 요청원이 없다.
- 일반 안내: guidanceTrackingActive일 때만 기준점 영역 진입으로 1회 요청. 같은 영역에 머무르면 추가 요청 없음. 같은 기준점 재진입 중복 방지는30초이며 앱 전체120초 예산 관리가 아니다.
- 기준점 수집: AP 수집 기능 있음.
- AP 강한 복구: verified/source>=3, 후보 점수 등과 함께 새 스캔3회, 인접 스캔15초 이내를 요구한다. 현행 진입1회·같은 기준점30초 제한과 맞지 않아 일반적인 현행 흐름으로 발동하기 어렵다. 약한 AP 가중치 갱신과 구별해야 한다.

## 방향 변화 AP 정책 제안

자이로는 각속도이며 휴대폰 회전과 보행 방향 전환을 구별하지 못한다. 회전 하나로 계단 또는 두리번거림을 확정할 수 없다. 회전벡터 방위의 지속 변화, 실제 걸음, 연결 가능한 분기, 층 전이는 기압 추세를 함께 본다.

AP 요청 조건은 OR로 구성한다: 기준점 근접 / 걸음 동반 지속 방향전환 / 추적 불확실성 증가. 회전은 추가 요청 사유이지 위치 정답이 아니다. 직선으로 코어를 통과할 때도 스캔 기회를 보존한다.

하나의 회전 묶음은 1회 요청하고 첫 결과가 불충분하며 추가 정보가 기대되는 경우에만 최대2번째 요청. 같은 묶음의 반복 회전은 추가 요청하지 않는다. 앱 전체 최근120초 최대4회 요청 이력을 유지하고, 응답 대기중 중복 요청과 제한 실패 재시도 폭주를 막는다. 실제 OS 허용 및 새 결과 여부를 확인한다. Android는 고정30초마다 성공 보장이 아니라 전경 앱2분4회 제한이다.

움직이는 동안의 스캔은 요청 순간 좌표로 정답 라벨을 찍지 않는다. AP별 관측시각과 요청~응답 동안의 PDR 이동량을 저장하고 측정시각에 맞는 후보로 비교하거나 이동량만큼 불확실성을 넓힌다. 계단 층 전이 중 관측은 특정 층 앵커에 강하게 붙이지 않는다.
