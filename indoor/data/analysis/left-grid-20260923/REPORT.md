# 4층 왼쪽 자기장 격자 구축 및 평가

기존 왕복 5회, 실측 코어~왼쪽 계단 거리 48.835m, 0.5m 격자. 각 회차의 검출 걸음 진행률로 실측 양 끝 사이에 자기장 크기를 정렬하고, 회차별 선형 보간값을 격자에서 평균/분산으로 집계했다. 중간 좌표는 약한 라벨이며 실제 중간 위치를 측량한 것이 아니다.

평가는 매번 평가 회차의 SHA256을 지도 생성에서 제외한 4회 지도와 실제 Runtime으로 실행했다. BLE는 별도 기준점 자료이며 평가 로그의 랩은 추적기에 넣지 않았다.

| 구성 | 평균 종점 오차 m | 최대 m | 격자 적용 |
|---|---:|---:|---:|
| pdr | 1.986 | 3.682 | 0 |
| v2_ble | 1.972 | 3.689 | 0 |
| grid | 1.942 | 3.592 | 17 |
| grid_ble | 1.929 | 3.600 | 17 |
| hybrid_ble | 1.928 | 3.599 | 17 |

격자 단독 추가는 평균 0.0435m 개선, 4회 개선/1회 악화. 203035 회차는 0.097→0.222m로 악화했다. 효과는 작아 일반화된 우월성이나 중간 위치 정확도를 보장하지 않는다. BLE/V2까지 포함하면 평균 1.928m이나 복잡성 대비 추가 이득이 작다.

Runtime과 파티클 격자 관측은 명시적 main_left 좌표 옵션을 지원하도록 확장했다. 기본값은 기존 main_right이며 앱 로더는 아직 왼쪽 지도를 선택하지 않는다. 결과 지도는 분석 폴더의 grid-4f-left.json에 저장했다. APK 기본 설정 및 설치본은 변경하지 않았다. 5회 전체 지도는 배포 후보이고 LOSO 평가 지도와 다르다.

검증: 기존 오른쪽 격자 회귀, 왼쪽 좌표/구역/층 제한, 평가 회차 제외, BLE/AP 지원 보존 및 V2 회귀 통과. 다음 단계는 독립 보행에서 왼쪽 격자 후보와 기존 V2를 비교하고 채택 여부를 정하는 것이다.
