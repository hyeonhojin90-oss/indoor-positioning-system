# 왼쪽 자료 반영·m_v·PDR 비교 (2026-09-23)

## 적용

9/22 왼쪽 정방향2/역방향3회에서 실제 Runtime 검출기를 사용해 8걸음 지문173개를 생성했다. 시작/끝은 사용자의 경로 라벨과 공용 실측 거리표를 사용하고 중간은 검출걸음 진행률로 정렬했다. 48.8350512m 코어↔왼쪽 계단 구간이다. 운영 motion-models.json의 Android4층 왼쪽 지문만 교체했다. 원본과 오른쪽/다른층 지문은 보존한다. 모델 원본은 motion-models-before.json에 백업했다.

sequence.match에 좌우 복도 후보 분리를 추가해 왼쪽 진행 중 오른쪽 지문을 고르는 문제를 막았다. 기준 구역을 모르는 코어에서는 강제 좌우 필터를 하지 않는다. m_v는 인과 가속도 EMA 중력 투영으로 계산하며 verticalSequenceEnabled 명시 옵션으로만 점수에 추가한다. 운영 기본값은 꺼짐. 기존 manifest 생성기는 새 지문을 덮어쓰지 않도록 중단 가드를 추가했다. APK 빌드/설치 없음.

## 무엇이 정답인가

- 종점: 공용 실측 거리표의 코어/계단 기준선 + 실제 해당 위치에서 누른 마지막 랩. 특정 보행 파일의 PDR 궤적을 정답으로 쓰지 않는다. 랩 위치/누른 시각이 틀리면 이 평가도 영향을 받는다.
- 강의실 랩: 문 위치를 실측하지 않은 도식 좌표라면 약한 정답이다. 지도 그림을 실제 위치 정답으로 간주하지 않는다.
- 중간 궤적: 시작/끝 사이를 검출걸음 수로 보간한 약한 정답이다. 보폭 일정 가정과 검출 오차가 있으므로 실제 미터 정확도를 인증하지 못한다.
- 학습: 학습 회차의 종점/랩으로 지문을 정렬할 수 있다. 시험 회차는 파일/해시로 학습에서 완전히 제외한다. 시험 엔진에는 시작점과 원시 센서만 전달하며 도착 랩은 평가 종료 시각에만 쓴다.

## 실제 Runtime 5회 LOSO

BLE는 기존 별도 정지 지문, 최소4개 조건을 모든 BLE 실험군에서 동일하게 사용한다. 자기장 지문은 시험 회차 해시 제외. AP는 보행 로그에 없으므로 평가하지 못했다. 같은 날/사용자/기기 결과다.

|조건|종점 평균오차 m|최악 m|자기장 적용 합계|BLE 적용 합계|
|---|---:|---:|---:|---:|
|PDR+지도 파티클, 자기장/BLE 끔|1.986|3.682|0|0|
|위 조건+BLE|2.922|5.174|0|12|
|BLE+새 크기 V2|2.844|5.174|1|12|
|BLE+새 크기+m_v V2|2.920|5.174|4|12|

크기 V2는 BLE-only보다 소폭 개선하지만 전체 조합은 무보정 기준보다 나쁘다. m_v는 적용 횟수가 늘어도 효과가 입증되지 않았다. 이번 반영은 누락 지문과 좌우 후보 오류를 바로잡는 실험용 갱신이며 최적 엔진 인증이 아니다. 왼쪽 격자지도 실험과도 다르다.

191741 역방향은 BLE를 켜면1.838→5.174m, 211757은3.682→5.107m다. BLE는 관측을 계속하되 기준점 신호가 보인다고 기준점 한 점에 끌어당기는 제안 파티클 처리를 다음 A/B에서 분리할 필요가 있다. 현재 observeRadio는 강한 후보 시15% 파티클을 앵커 주변에 생성한다. 신호 감지 범위와 정확 좌표가 다르며 이번 실험만으로 파티클 제안이 유일 원인이라고 확정하지 않는다.

## 보폭 단독 재평가

`evaluate_adaptive_weinberg_android_4f.cjs --left`를 추가해 왼쪽5회도 동일 고정보폭 및 회차 제외 계수 학습으로 비교했다. 오른쪽6회도 재실행했다. 이는 검출걸음별 보폭 합산 거리이며 위 파티클/지도/BLE 결과와 동일 척도의 엔진 비교가 아니다.

상수 K도 걸음별 가속도 진폭에 따라 보폭이 변한다. 현재 가장 유망한 후보이나 좌우를 따로 학습한 진단이므로 전층 공통 모델이 검증된 것은 아니다. 다음은 좌우 통합 학습/회차 제외 평가 및 실제 모드4 보폭 입력 교체 A/B다. RoNIN은 기존 보고서에서 미실행 후보이며 이번에 실행하지 않았다. 새로운 사용자 일반화도 미검증이다.

## AP와 BLE 역할

보행 중 BLE 지속 관측은 유지한다. 정확한 진행량 보정은 구별력/동시 자기장/연속성 근거가 있어야 한다. AP는 회전/불확실성 사건에서 요청해도 수집된 코어·계단 지문에 반드시 해당하지 않는다. 절대 적합도가 부족하면 unknown/보류로 남겨야 한다. 가장 가까운 기준점을 무조건 정답으로 선택하면 안 된다. 현재 자료에는 중간 구간 음성 예제 부족이 있어 코어/계단 밖 오탐률을 인증할 수 없다. AP 이벤트 스케줄러는 이번에 구현하지 않았다.
