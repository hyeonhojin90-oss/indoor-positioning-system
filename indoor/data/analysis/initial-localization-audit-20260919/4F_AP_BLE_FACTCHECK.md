# 4층 복도 AP·BLE 구분력 팩트체크

작성일: 2026-09-19

## 확인 질문

1. 4층 복도 중간 AP가 실제로 비슷한가?
2. AP를 코어·양끝 계단에 제한하더라도 BLE는 복도 중간에서 계속 사용해야 하는가?

## AP 결과

회차 제외 Wi-Fi 판별은 13회 중 11회 정답(84.6%)이었지만, 오답 2회가 모두 오른쪽 복도 중간 기준점이었다.

|실제 위치|1순위|RSSI MAE|정답 후보|RSSI MAE|판정|
|---|---|---:|---|---:|---|
|4209 앞|코어|9.93 dB|오른쪽 복도|10.21 dB|오답|
|4206 앞|오른쪽 계단|10.18 dB|오른쪽 복도|10.21 dB|오답|

4209와 4206의 직접 비교에서는 AP 71개가 공통이었고 합집합 174개, Jaccard 0.408, 공통 AP RSSI MAE 10.21 dB였다. 이 차이는 `오른쪽 복도↔오른쪽 계단` 세션쌍 중앙 10.72 dB, `오른쪽 복도↔코어` 11.67 dB와 충분히 분리되지 않았다.

왼쪽 복도의 4225와 4124는 공통 AP 90개, Jaccard 0.604, RSSI MAE 4.73 dB로 더 비슷했다. 두 세션은 `main_left` 큰 구역은 맞혔지만 복도 안 진행 위치를 구분하는 근거는 되지 않는다.

반면 새 AP가 있었고 회차 제외 평가가 가능한 코어 3회, 오른쪽 계단 3회, 왼쪽 계단 3회는 모두 자기 구역을 1순위로 맞혔다. 따라서 현재 자료는 AP를 복도 내부 진행량보다 코어·계단 같은 위상 기준점 확인에 쓰는 방향을 지지한다.

## BLE 결과

정지 기준점 회차 제외 BLE 판별은 16회 중 12회 정답(75.0%)이었다. 오른쪽 복도 4209와 4206은 AP와 마찬가지로 각각 코어와 오른쪽 계단으로 오판됐다. 코어에서도 초기 세션 2회가 공통 신호 수가 매우 적은 다른 구역으로 오판됐다.

별도 실제 보행 5초 창에서도 다음이 확인됐다.

- 오른쪽 복도 4207~4212 일부가 코어로 판정됨
- 왼쪽 복도 4120 부근에서 코어/오른쪽 기준점 오판
- 왼쪽 복도 4122 부근에서 오른쪽 계단 오판
- 오른쪽 복도 중간에서 코어 판정과 신호 부족 발생

BLE는 복도 중간에서 끄는 센서가 아니다. 연속 관측하되 PDR 12m 게이트 안에서 파티클을 약하게 재가중하고, 단독으로 강의실 앞이나 진행 좌표를 확정하지 않는 것이 현재 자료에 맞다.

## 적용 해석

- PDR·지도: 항상 주 추적
- 자기장 8걸음: 복도 진행량 후보의 약한 보정
- BLE: 복도 전체에서 연속 관측하되 약한 보정과 구역 순서 확인
- AP: 코어·양끝 계단 같은 구분력 있는 기준점에서만 새 스캔을 요청하는 희소 보정

AP와 BLE 모두 `calibratedProbability`가 아니다. 위 결과는 같은 Galaxy 정지/보행 자료의 상대 신호 비교이며 다른 사용자·기기 일반화를 증명하지 않는다.
