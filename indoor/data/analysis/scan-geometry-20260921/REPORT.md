## 사용자 정정: 촬영 경계와 측정 기준선 분리

새 왼쪽 스캔은 화장실 왼쪽선에 맞춰 잘린 자료가 아니다. 사용자 설명대로 화장실 오른쪽 일부까지 포함한다. GLB 뷰어와 평면 투영을 다시 확인했으며, 화장실 쪽 확장 형상 너머로 촬영 형상이 더 이어진다. 따라서 전체 외곽 49.394m와 낮은 수평면 범위 46.809m 모두 화장실 왼쪽선에서 잰 길이가 아니다.

측정 기준은 확정됐다. 새 GLB **내부의 화장실 왼쪽선 → 왼쪽 복도 끝**을 재고, 기존 코어 자료의 **코어 왼쪽선 → 같은 화장실 왼쪽선**을 연결한다. 공통 기준선을 맞춰 두 구간을 합산하며 코어 폭·계단 내부·겹친 촬영 영역을 추가하지 않는다. 촬영 시작점을 사용자에게 다시 확인할 문제가 아니라 기존 자료에서 해당 경계의 좌표를 대응시킬 작업이다.

이번 재확인에서는 경계의 정확한 메시 좌표와 합산 미터값까지 확정하지 않았다. 기존 9/15 검사도 화장실 왼쪽선의 좌표 정합을 미완료로 기록하고 있으므로, 기존 파일에 확정 거리가 있다고 취급하지 않는다. `length_m=null`을 유지하며 지도와 PDR 거리축은 변경하지 않았다.
