# 1층 제외 전층 공통 거리 및 3층 증축부 실측 반영

## 적용 범위

- [x] 2~10층 공통 오른쪽 복도: 코어 경계부터 계단 진입 전까지 48.685m
- [x] 2~10층 공통 코어 폭: 벽 중심 기준 2.975m
- [x] 2~10층 공통 왼쪽 복도: 코어 왼쪽 경계부터 복도 끝까지 47.347m
- [x] 3층 증축부 직선: 길이 25.244m, 폭 2.059m
- [x] 3층 증축 전면공간: 14.284m × 6.794m
- [x] 1층 제외

오른쪽 복도·코어·왼쪽 복도를 연결한 물리축은 총 99.008m다. 3층 새 스캔의 50.884m는 코어 쪽 벽부터 스캔 끝벽까지이며, 기존 48.685m는 계단 **진입 전**까지다. 측위 목적지 기준은 계단 진입 전이므로 50.884m를 다시 더하지 않아 계단 깊이의 중복 적용을 막았다.

## 엔진 반영

`areas-v1.json`의 2~10층에 동일한 구간별 물리 거리표를 적용했다. 1층은 `distanceMetric=null`을 유지한다.

| 지도축 기준점 | 누적 실거리 |
|---|---:|
| 오른쪽 계단 진입 전 `x=3.3631` | 0m |
| 코어 오른쪽 경계 `x=69.424` | 48.685m |
| 코어 왼쪽 경계 `x=72.184` | 51.661m |
| 왼쪽 복도 끝 `x=135.407` | 99.008m |

기존 지도 좌표는 강의실 배치와 화면 표시를 위해 유지하되, PDR 한 걸음은 위 표에서 물리 미터로 변환한다. 새 코어 폭을 반영해 공통 변환계수는 `0.7086199567m/legacy-unit`으로 다시 계산했다. 이는 기본 81걸음이 코어 중앙에서 오른쪽 계단 진입 전까지 도달하도록 한 기존 기준을 실측 코어 폭에 맞춘 값이다.

`navigation.js`는 기존 세 기준점 전용 계산을 임의 개수의 구간별 기준점으로 일반화했다. 따라서 오른쪽 복도뿐 아니라 코어와 왼쪽 복도에서도 같은 방식으로 실제 거리 누적과 역방향 이동을 계산한다.

## 3층 지도 반영

3층은 `floor-03-survey.json`을 추가하고 2D·3D·navigation의 증축 직선과 전면공간을 같은 GLB 치수로 생성한다. 3D와 2D에서 보이던 약 26.57m/5.02m 증축 직선을 25.244m/2.059m로 정합했다.

IT홀은 사용자가 앞서 설명한 것처럼 입구 옆 존재와 외곽 연결 관계는 확인됐지만 내부를 들어가 측정한 자료는 아니다. IT홀 내부, 3104-1·2 방 내부와 문별 좌표는 미측정 상태로 유지했다. 이 미확정 항목은 메인복도와 증축 직선의 진행거리 계산에는 사용하지 않는다.

## 기존 로그 확인

공통 실거리 적용 후 2층 메인복도 기존 로그를 재생했다. 다음은 랩 목적지와 추정 종점의 물리축 차이다.

| 경로 | 검출 걸음 | 남은 물리 오차 |
|---|---:|---:|
| 2F 코어→왼쪽 계단, 9/1 | 79 | 2.35m |
| 2F 코어→오른쪽 계단, 9/1 | 77 | 3.00m |
| 2F 코어→왼쪽 계단, 9/19 | 67 | 8.20m |
| 2F 왼쪽 계단→코어, 9/19 | 64 | 8.92m |
| 2F 코어→오른쪽 계단, 9/19 | 92 | 3.15m |
| 2F 오른쪽 계단→코어, 9/19 | 106 | 5.15m |

이제 위 오차에는 잘못된 복도 축척을 정답으로 사용한 오차가 포함되지 않는다. 남은 차이는 랩 위치, 걸음 검출 수, 고정보폭과 실제 보폭, 방향·보정의 영향으로 평가한다.

2층 증축부 대용 잔차는 새 공통 변환계수로 다시 재생해 정방향 3.81→3.98m, 역방향 5.33→6.19m였다. 마지막 랩 위치가 측량 좌표가 아니므로 이 값을 보폭 학습 정답으로 사용하지 않는다.
