# IT융합대학 3층 재구성 근거 분석

## 분석 대상

- `it_4f_prototype/assets/3f/it_3f_right_wing.glb`
- `it_4f_prototype/assets/3f/it_3f_spatial_report.pdf`
- 사용자가 표시한 3층 GLB 상단 이미지
- 기존 3층 피난안내도
- 기존 4층 공통 구조 모델

## 확정

- 3층 코어 복도와 왼쪽 복도 형상은 4층 구조를 그대로 재사용한다.
- 이 공통부의 강의실 번호와 방 분할 표시는 3층 피난안내도로 다시 매핑한다.
- 3층 오른쪽 복도와 저층 확장부 형상은 새 GLB와 Polycam 보고서를 우선한다.
- 3층의 끝 화장실 통로와 사이드계단은 4층 공통 구조를 그대로 재사용하며, 별도 계단을 중복 생성하지 않는다.
- 위에서 본 3층 신규 공간은 확장 복도 진행 방향의 왼쪽으로 분기한다.
- 새 GLB의 원시 bounding box는 약 `39.8218 × 7.3823 × 53.0394m`이다.
- GLB에는 메시 6개, 재질 6개, 텍스처 6개가 있으며 별도 노드 이동·회전·스케일 값은 없다.
- 초록색 화살표는 기존 오른쪽 복도에서 확장부 접속점으로 들어오는 진행 방향이다.
- 흰색 표시는 사이드계단 입구다.
- 파란색 표시는 IT홀 입구다.
- 분홍색 화살표는 접속점에서 새로 연결되는 넓은 공간 방향이다.
- GLB에 보이는 문과 개구부는 최종 클레이 모델에서도 제거하거나 벽으로 막지 않는다.
- 빨간 경계선 오른쪽은 4층 구조를 그대로 유지한다.
- 노란색 구간은 신규 공간으로 들어가는 폭 약 `6.121m`의 개방부이며 일반 단일 출입문으로 축소하지 않는다.
- 신규 공간의 기준 크기는 약 `25.317m x 6.964m`로 사용한다.
- 파란색 구간은 IT홀 방향 계단이며 기준 폭은 약 `2.422m`이다.
- Polycam 보고서는 세 공간을 `Room 1`, `Room 2`, `Room 3`으로 분리한다.
- 보고서상 Room 1에는 창 1개와 문 2개, Room 2에는 창 2개와 문 1개 및 계단 1개가 감지되어 있다.

## 자료 해석

- Polycam 공식 샘플 보고서는 다른 공간의 예시 자료이므로 3층 형상, 치수, 문, 계단 배치의 근거로 사용하지 않는다.
- `Openings`의 문과 창 개수·폭·높이는 벽 생성 시 개구부를 보존하는 근거로 사용한다.
- `Room 1`, `Room 2` 같은 자동 이름은 실제 강의실명이 아니라 스캔 과정에서 분리된 공간 단위다.
- 보고서 수치는 추정치이므로 GLB에서 직접 확인되는 형상과 충돌하면 GLB를 우선하고, 중요한 축척은 현장 실측으로 다시 검증한다.

- `Room 1`: 길게 이어지는 오른쪽 복도 구간과 그 벽면 개구부를 설명하는 자료로 본다.
- `Room 2`: IT홀 입구, 사이드계단과 넓은 신규 공간이 만나는 접속부를 설명하는 자료로 본다.
- `Room 3`: 접속부의 작은 별도 공간 후보이며 정확한 명칭은 아직 확정하지 않는다.
- 현재 3층 보고서에서 확인할 수 없는 수치는 임의로 채우지 않으며, 실제 GLB 형상과 사용자 표시를 사용한다.
- 길이와 상대 비율은 GLB 좌표 및 평면도 형상을 우선하고, 보고서는 문·창·계단의 존재 검증에 사용한다.

## 정합 기준점

1. 기존 오른쪽 복도 중심선과 초록색 진입선의 중심
2. 사이드계단 입구 중앙
3. IT홀 입구 중앙
4. 분홍색 신규 공간으로 꺾이는 코너
5. 빨간색 표시 위치
6. Polycam Room 1과 Room 2가 만나는 경계

4층 공통부를 복제한 뒤 1번과 2번 기준점을 먼저 맞추고, 나머지 기준점의 오차를 확인한다.

## 추정 또는 미확정

- 빨간색 표시는 위치가 확인되지만, 벽·문·경계 중 어떤 형상을 뜻하는지는 아직 확정하지 않는다.
- `Room 3`의 실제 명칭과 용도는 미확정이다.
- GLB의 원시 X/Z축을 건물 전체 좌표의 어느 축으로 변환할지는 공통 복도와 사이드계단 기준점으로 계산해야 한다.
- 3층 강의실 번호는 피난안내도에서 읽은 후보이므로 실제 문 위치와 대조한 뒤 확정한다.
- 층고는 현장 실측 전까지 기존 `4.0m provisional` 값을 사용한다.

## 구현 원칙

- 공통부와 확장부를 한 번에 다시 그리지 않는다.
- `4층 공통부 복제 → 3층 방 번호 재매핑 → GLB 확장부 정합 → 문·계단 검증` 순서로 작업한다.
- 빨간 표시의 의미가 확정되기 전에는 해당 위치의 GLB 형상을 그대로 유지한다.
- 구조 확인용으로 `scan3f.html`에서 원본 GLB를 언제든 대조한다.
