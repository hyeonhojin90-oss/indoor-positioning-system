# IT융합대학 3층 재구성 작업 프롬프트

## 작업 목표

조선대학교 IT융합대학 3층을 실제 내부 구조에 가깝게 재구성하고, 기존 4층 모델과 동일한 좌표계에 정합하여 이후 여러 층을 수직으로 쌓을 수 있게 한다.

이 작업에서는 보기 좋은 임의 모델보다 **자료에서 확인되는 실제 구조와 비율을 보존하는 것**을 우선한다. 구현 전에 자료를 분석하고, 확정되지 않은 부분을 분리한 뒤 모델링한다.

## 자료 우선순위

자료가 서로 다를 경우 다음 순서를 따른다.

1. **GLB/LiDAR 스캔**
   - 벽, 복도, 문, 개구부, 계단, 엘리베이터, 화장실, 기둥, 꺾임, 공간의 방향과 상대 비율을 판단하는 1차 기준이다.
   - GLB에서 확인되는 문과 통로는 모두 보존한다.
2. **Polycam 평면도와 공간 보고서**
   - GLB의 길이, 폭, 면적, 계단 및 문의 치수를 검증하고 스케일을 보정하는 기준이다.
3. **현장 사진과 사용자의 방향 설명 및 실측값**
   - GLB의 촬영 누락, 방향 혼동, 공간 용도를 판별할 때 사용한다.
4. **피난안내도**
   - 강의실 번호, 강의실의 대략적인 순서, 시설 명칭을 매핑하는 용도로만 사용한다.
   - 벽 위치, 복도 폭, 방 크기, 코어 형상 또는 전체 비율을 피난안내도만 보고 결정하지 않는다.

## 절대 규칙

- GLB에 존재하는 문, 출입구, 개구부, 복도 분기와 계단 입구를 임의로 삭제하거나 막지 않는다.
- 근거 없이 벽, 방, 통로, 문 또는 빈 공간을 새로 만들지 않는다.
- 스캔이 비어 있거나 깨진 부분을 곧바로 벽 또는 열린 공간으로 해석하지 않는다. 해당 영역은 `미확정`으로 기록한다.
- GLB와 평면도의 방향을 확인하지 않은 상태에서 좌우 반전, 회전 또는 재배치를 하지 않는다.
- `건물 정면 기준 좌우`와 `엘리베이터에서 내린 사람 기준 좌우`를 항상 구분해 기록한다.
- 공간 형상을 먼저 확정하고, 그다음 강의실 번호를 매핑한다. 번호에 맞추기 위해 공간 형상을 변형하지 않는다.
- 확정되지 않은 치수를 임의의 보기 좋은 값으로 채우지 않는다. 임시값이 꼭 필요하면 코드와 문서에 `provisional`로 표시한다.
- 모델 수정 전에 무엇이 확정이고 무엇이 추정인지 사용자에게 먼저 보고한다.

## 4층과의 수직 정합 기준

3층 모델은 독립된 장면으로 만들지 않고 기존 4층 모델과 다음 기준을 공유한다.

- 동일한 미터 단위와 축 방향
- 엘리베이터 2개의 중심축
- 메인계단과 양쪽 끝 계단의 중심축
- 코어 복도와 메인 복도의 교차 기준점
- 외벽 또는 장축 복도 중심선
- 층 바닥 높이 기준

층고가 실측으로 확정되지 않았다면 수평 정합만 먼저 완료하고, 층고는 `provisional` 값으로 분리한다. 엘리베이터와 계단이 층마다 옆으로 이동하지 않도록 수직축 정합 검사를 수행한다.

## 층별 건물 구조 규칙

건물 전체를 층마다 독립적으로 다시 만들지 않고 다음 두 유형으로 구분한다.

### 4~10층: 표준층

- 4층 구조를 표준층 원본으로 사용한다.
- 5~10층은 기본적으로 4층의 벽, 복도, 코어, 엘리베이터, 계단 및 외곽 형상을 같은 위치에 수직 복제한다.
- 층별 강의실 번호와 실제 현장 차이가 확인되기 전에는 표준층의 형상을 임의로 바꾸지 않는다.
- 이후 발견되는 문, 시설 또는 내부 칸막이 차이는 표준층 원본을 훼손하지 않고 층별 오버라이드로 관리한다.

### 1~3층: 저층 확장형

- 1~3층 전체가 서로 완전히 다른 구조는 아니다.
- 기존 왼쪽 복도 라인은 4층과 같은 공통 구조를 유지한다.
- 기존 오른쪽 복도 쪽에는 `|`자 형태의 추가 건물 동이 연결되며, 이 세로 동은 1~3층에서 사용된다.
- 따라서 3층은 `표준층 공통부 + 저층 세로 동`으로 구성한다.
- 1층과 2층도 같은 저층 확장 원칙을 공유하지만, 각 층의 문, 방 분할과 용도는 해당 층 자료로 별도 검증한다.
- 3층 끝 화장실 통로와 사이드계단은 4층과 같은 공통 구조를 재사용하며 3층 전용 계단을 중복 생성하지 않는다.
- 화장실 통로 다음 약 `1.77m` 벽이 끝나는 지점부터 계단 입구가 열리고, 입구 이후 같은 복도 경계에 벽을 더 연장하지 않는다.
- 위에서 볼 때 3층 신규 공간과 IT홀은 세로 확장 복도의 왼쪽으로 분기하고, `3104-1/2`는 반대편에 둔다.

여기서 `왼쪽 복도`와 `오른쪽 복도`는 현재 프로젝트에서 사용해 온 임시 구역명이다. 구현 전 좌표계 문서에 각 구역의 X축 범위와 `건물 정면 기준` 또는 `엘리베이터 하차 기준`을 함께 적어 좌우 반전을 방지한다.

## 모델 재사용 구조

권장 모델 계층은 다음과 같다.

```text
building
├─ shared_core          # 엘리베이터 2개, 메인계단, 공통 수직축
├─ standard_floor       # 4층에서 확정한 공통 본체
├─ low_floor_extension  # 1~3층의 |자 세로 동
└─ floor_overrides      # 층별 문, 칸막이, 강의실 번호와 시설 차이
```

3층 작업에서는 4층 공통부를 새로 추정하지 않는다. 먼저 4층 표준층을 복제하고, 3층 GLB와 보고서에서 확인되는 차이 및 `|`자 세로 동만 분리해 추가하거나 수정한다.

## 구현 전 필수 분석

코드를 수정하기 전에 다음 결과를 먼저 작성한다.

1. **자료 목록**: 각 GLB, PDF, 평면도, 사진이 어느 구간을 담고 있는지 정리
2. **좌표 규칙**: 원점, X/Y/Z 방향, 건물 정면과 엘리베이터 기준 방향 명시
3. **GLB 검사 결과**: 파일별 단위, bounding box, 회전값, 유효 메시 및 촬영 누락 구간
4. **확정 구조표**: 복도, 코어, 계단, 엘리베이터, 화장실, 문과 개구부 목록
5. **근거 상태표**: 각 요소를 `확정`, `추정`, `미확정`으로 분류하고 근거 파일 기록
6. **정합 기준점**: 서로 다른 GLB와 4층 모델을 연결할 기준점 3~6개 이상 제시
7. **불일치 목록**: GLB, 보고서, 사진, 피난안내도가 서로 다른 부분 기록
8. **수정 예정안**: 실제 코드 변경 전에 배치도 또는 좌표표로 제시

미확정 사항이 모델의 구조를 바꿀 정도로 중요하면 추측하여 진행하지 말고 사용자에게 확인한다.

## 권장 작업 순서

1. 3층 자료를 구간별로 분류한다.
2. GLB를 시각적으로 확인하고 메시의 크기, 방향, 문, 개구부, 계단 및 시설을 추출한다.
3. Polycam 평면도와 보고서의 실측 치수로 GLB 스케일을 검증한다.
4. 같은 구조물이 중복 촬영된 지점을 기준점으로 삼아 GLB들을 정합한다.
5. 4층의 엘리베이터·계단 축과 3층 코어를 먼저 맞춘다.
6. 4층 표준층 공통부와 1~3층용 `|`자 세로 동의 결합 위치를 확정한다.
7. 강의실 번호가 없는 순수 3층 구조 모델을 만든다.
8. 평면도, GLB, 사진을 다시 대조해 문과 통로가 막히지 않았는지 확인한다.
9. 피난안내도를 이용해 강의실 번호만 매핑한다.
10. 이동 가능한 복도 중심선과 출입구를 기준으로 경로 그래프를 만든다.
11. 4층 위아래에 쌓아 수직축과 충돌 여부를 검증한다.

## 검증 조건

- 위에서 본 화면, 사선 3D 화면, 사람 눈높이 화면을 각각 캡처해 비교한다.
- 모든 GLB 문과 개구부가 모델에 존재하는지 체크리스트로 대조한다.
- 복도 경로가 벽이나 강의실을 통과하지 않는지 확인한다.
- 계단 및 엘리베이터가 강의실과 겹치지 않는지 확인한다.
- 3층과 4층의 엘리베이터 2개 및 계단 축이 수직으로 맞는지 확인한다.
- 모바일과 데스크톱에서 모델이 비어 보이지 않고 회전·확대·축소가 작동하는지 확인한다.

## 작업 보고 형식

구현 전에는 다음 형식으로 보고한다.

```text
[확정]
- 요소 / 치수 / 방향 / 근거 파일

[추정]
- 요소 / 현재 추정 / 추정 근거 / 영향 범위

[미확정]
- 확인이 필요한 질문 / 확인되지 않으면 생기는 문제

[정합 기준점]
- 기준점 이름 / GLB 좌표 / 모델 좌표 / 연결 자료

[수정 예정]
- 파일 / 변경할 구조 / 검증 방법
```

이 보고가 끝나고 구조적 모순이 해소된 뒤에만 실제 모델 코드를 수정한다.
