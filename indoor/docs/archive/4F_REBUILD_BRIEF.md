# IT융합대학 4층 클레이 3D 재구성 브리프

작성일: 2026-08-16

## 1. 작업 목적

4층 LiDAR 스캔 원본을 그대로 합치는 것이 아니라, 피난안내도, 현장 사진, LiDAR 평면도, GLB 스캔, 자기장 측정값을 참고하여 안내용으로 깔끔한 클레이형 3D 지도를 다시 만든다.

최종 지도는 다음 기능을 지원해야 한다.

- 엘레베이터 허브에서 출발
- 메인 복도 진입
- 목적 강의실까지 경로 표시
- 강의실 번호 표시 토글
- 계단/엘레베이터 구분
- PDR/자기장 보정 위치 표시 확장 가능

## 2. 제공된 자료 정리

### 2.1 피난안내도 사진

사용자가 제공한 1~4층 피난안내도는 강의실 번호와 순서의 확인 자료로만 사용한다. 실제 공간 형상과 치수의 1차 기준은 GLB 및 Polycam 평면도다.

4층 피난안내도에서 확인된 점:

- 전체 구조는 사용자가 말한 것처럼 위에서 보면 `ㅗ`에 가깝다.

## 3. 현재 모델의 문제점

현재 `clay.html` / `src/clay4f.js` 클레이 모델은 다음 문제가 있다.

1. 엘레베이터/계단 허브는 추가됐지만 실제 `ㅗ` 구조가 완전히 맞지 않다.
2. 계단과 엘레베이터의 좌우 위치가 반대로 들어간 것으로 보인다.
3. 현재 화면 기준에서 왼쪽/오른쪽 복도 방향 자체는 맞지만, 방 배치가 반대로 들어갔다.
4. 4213의 방향이 잘못 표시됨.
   - 사용자의 최신 지적: 4213은 오른쪽으로 가야 나오는 곳.
   - 4213은 건물 안쪽에 있는 느낌.
5. 엘레베이터에 가까운 쪽은 4218 강의실이다.
6. 바깥쪽으로 갈수록 4210 등이 나오는 구조로 이해해야 한다.
7. 현재 모델은 4213과 4218, 4210의 상대 위치가 반대로 들어간 가능성이 높다.

## 4. 최신 구조 이해

사용자의 최신 설명을 기준으로 다음처럼 이해한다.

### 4.1 전체 형태

위에서 본 4층 구조는 `ㅜ`가 아니라 `ㅗ`이다.

즉:

- 긴 가로 복도 = 메인 복도
- 엘레베이터/계단 허브 = 메인 복도에서 아래쪽으로 붙은 세로 줄기
- 사용자는 엘레베이터 허브에서 나와 메인 복도에 진입한 뒤 좌우 중 하나로 이동한다.

### 4.2 방향 기준

현재 3D 화면 기준:

- 화면 왼쪽 = 엘레베이터 기준 왼쪽 방향
- 화면 오른쪽 = 엘레베이터 기준 오른쪽 방향

다만 정문 기준 건물 좌우와는 반대로 느껴질 수 있으므로, 안내문은 항상 다음 형식으로 쓴다.

- 엘레베이터에서 내려 왼쪽
- 엘레베이터에서 내려 오른쪽

### 4.3 방 배치 수정 가설

최신 사용자 지적 기준:

- 4213은 오른쪽으로 가야 나오는 곳.
- 4213은 건물 안쪽에 있는 쪽.
- 엘레베이터에 가까운 쪽은 4218.
- 바깥쪽은 4210 쪽.

따라서 기존 데이터에서 단순히 `4213~4204 = 왼쪽`, `4218~4228 = 오른쪽`으로 둔 것은 재검토해야 한다.

다음 작업 전 확인 필요:

- 4213, 4218, 4210이 각각 엘레베이터 기준 어느 방향에 있는지 최종 확정
- 4120~4128이 메인 복도 아래쪽 어느 구간에 붙는지 최종 확정
- 계단과 엘레베이터의 좌우 위치 최종 확정

## 7. 4f-v0.6 정합 결과

- 전체 좌표계는 GLB 직접 측정을 우선해 메인 복도 왼쪽 끝 `x=0`, 오른쪽 끝 `x=125.113`, 중심선 `y=0`으로 통일했다.
- 엘레베이터 기준 왼쪽 복도는 `64.437 m`, 중앙 빨간 연결 구간은 `2.44 m`, 오른쪽 복도는 `58.236 m`로 사용한다.
- 중앙 연결 구간 `x=64.437~66.877`에는 강의실을 배치하지 않는다.
- 허브 GLB의 평면도와 추가 설명을 대조해 메인 복도 제외 코어 깊이는 약 `9.17~9.23 m`로 사용한다.
- GLB 전체 바운딩박스 `12.734 m`는 계단·엘레베이터 외곽 참고값이며, 메인 복도 중앙 간격으로 사용하지 않는다.
- `4213~4204` 전체 줄과 `4218~4228` 전체 줄은 화면상 복도 아래쪽 같은 벽면에 둔다.
- `4120~4128`은 반대편인 복도 위쪽 줄에 둔다.
- 방 폭은 피난안내도에서 읽은 상대 비율을 유지하면서 좌우 GLB 복도 길이에 맞춰 각각 정규화했다.
- 4213만 따로 이동시키는 방식은 폐기했고, 모든 방은 행 단위 제약으로 관리한다.
- 위에서 보기 카메라는 엘레베이터 기준 좌우가 뒤집히지 않도록 방향축을 고정했다.

아직 재확인이 필요한 값은 각 강의실의 정확한 폭, 메인 복도 유효 폭, GLB 장거리 누적 오차와 중앙 연결부 기준점이다. 외부에서 잰 `107 m`는 참고값으로만 보존한다.

## 8. 4f-v0.8 중앙 코어 분리

- 허브 통로 자체의 폭은 수동 LiDAR 측정값인 약 `2.76 m`로 사용한다.
- GLB 코어 외곽 폭 `12.734 m` 전체를 강의실이 들어오지 않는 시설 구역으로 확보했다.
- `12.734 m`는 GLB 코어의 전체 가로 범위로 유지하되 양옆을 균등 분할하지 않는다.
- 메인 복도에서 `2.44 m` 뒤부터 계단이 시작되며, 첫 엘레베이터는 약 `3.59 m` 뒤에 나타난다.
- 코어복도 계단 측면은 메인복도부터 `2.44m`까지 벽, 이후 `1.0m` 계단문, 그 뒤부터 코어 끝까지 다시 벽으로 구성한다. 계단 뒤쪽 가로 경계도 벽으로 막는다.
- 메인계단 앞 `2.44m` 구간 내부는 보행 바닥으로 남기지 않고 고형 벽체로 채운다. 계단 두 런은 양쪽 측벽까지 폭을 확장해 옆 틈이 보이지 않도록 표현한다.
- 첫 엘레베이터 문 뒤에는 `2.27 m` 길이의 벽이 있고 그 다음 두 번째 엘레베이터가 나온다.
- 엘레베이터 문 폭 모델값 `1.10 m`를 적용하면 두 번째 엘레베이터 시작점은 메인 복도에서 약 `6.96 m`이다.
