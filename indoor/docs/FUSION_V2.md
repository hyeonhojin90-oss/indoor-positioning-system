# 실내측위 v2 비교 실험 — 2026-09-07

## 이번 적용

기존 안내·2D/3D·층별 보정 수집과 원시 로그는 유지한다. v1의 구역 판별, 영역 제약 파티클, 상대기압 층 상태 위에 다음을 추가했다.

| 기능 | 구현 및 적용 범위 |
|---|---|
| 센서 품질 | 자기장 변동·급변·범위 및 걸음 간격/피크로 관측 가중치와 이동 불확실성 조정. 초기 경험적 기준이며 현장 검증 전 |
| 자기장 시퀀스 | 8걸음 정규화 DTW, 같은 플랫폼·기기·층·방향 참조. 회전·3초 이상 정지 시 창 폐기. 상위 후보 기록, 자동 보정 기본 OFF |
| 보폭 모델 | 걸음 빈도·가속도 피크 Ridge 학습/회차 분리 평가. 기준 ±20% 제한, validated=false이므로 현재 고정 보폭 유지 |

AP 앵커는 현재 참조에 검증된 anchor 메타데이터가 없으므로 자동 복구는 발동하지 않는다. 이를 활성화하려고 기존 자기장 참조를 AP 앵커로 간주하거나 임의로 verified=true를 넣지 않는다. 1층 정문 앵커의 이동영역 정의도 추가 확인 필요하다.

## 학습 자료와 검증 제한

`indoor/tools/train_motion_models.cjs`가 manifest 허용 자료 중 2~10층 일반 좌/우 복도만 사용한다. 11회, 보폭 학습 행78개, 자기장 창423개. 원본 파일 해시를 평가 보고서에 포함했다. 사용자 제외 파일은 다시 넣지 않았다. 1층·증축부·IT홀 등의 경로는 직선 x 후처리를 적용하지 않는다.

- `indoor/data/analysis/motion-v2/evaluation.json`: 회차별 학습 제외 평가와 제외 이유.
- `lap-smoothed.json`: 랩 정합 좌표. **실측 위치 정답 아님.**
- `indoor/web/data/positioning/motion-models.json`: 플랫폼별 모델과 약한 위치 라벨 시퀀스.
- 보폭 MAE는 지도 거리/검출 걸음 기준이며 cm나 실제 보폭 오차율로 해석 불가. 구간 빈도에 멈춤 시간이 포함되어 런타임 한 걸음 빈도와도 차이가 있다.
- iOS 세 회차 중 두 회차의 모델 MAE가 기준보다 악화. Android 자기장 153038 회차는 수락 후보 2개에서 위치 오차 중앙값 약55.66 지도 단위. 따라서 자동 적용을 보류했다.
- 학습에 쓰인 회차를 실행 참조로 함께 탑재하지만, 평가에서는 대상 회차를 제외했다. 탑재 참조 재생 결과를 독립 정확도로 보고하지 않는다.

## 사용

Android: 새 APK 설치 후 **보정 수집 → 새 엔진 자유 위치 추적 시험**. 시작 층·코어 교차영역 또는 좌/우 계단 입구 지정 → 측정 시작 → 자유 이동 → 종료·저장. 시작 위치 없는 완전 자동 전역 탐색은 이번 화면에 구현하지 않았다. 휴대폰을 진행 방향으로 들고 측정한다.

AP는 시작 시와 `현재 AP 추가 관측` 버튼으로 수집하며 Android 스캔 제한·캐시를 별도 처리한다. 화면을 떠나거나 앱이 백그라운드로 가면 종료 저장한다. Downloads/IndoorPositioning의 schema6 원시/파생 로그를 확인한다. 원래 경로 수집과 동시에 실행하지 않는다.

Expo: 기존 자유 추적 화면에서 동일 센서 입력으로 `legacy_pdr`, `map_constraints_sequence_off`, `map_constraints_sequence_on`을 병렬 기록한다. ON/OFF의 차이는 8걸음 자기장 패턴뿐이며, ON도 후보 점수·분리도가 충분한 경우에만 위치 가중치를 반영한다. `derived_fusion.comparison_variant`와 `final_fusion_sequence_on`으로 구분한다. 보행 품질·복구 횟수·시퀀스 상태도 저장한다. 기존 보정 수집은 유지한다.

자유 추적 중에는 `실제 위치 라벨 기록`에서 층과 강의실 앞/코어 교차점/좌우 계단 입구를 직접 선택할 수 있다. 라벨에는 해당 지도 좌표와 같은 시점의 세 추정, 같은 층일 때의 x 오차가 `comparison`으로 저장된다. 이는 사용자가 현장에서 확인한 기준 라벨이며 자동 정답으로 만들어지지 않는다.

일반 보정 `경로 센서`도 코어·강의실·계단처럼 지도 기준점에서 시작하는 경로라면 같은 병렬 비교를 자동 시작한다. `현재 지점 기록` 랩은 실제 위치 라벨이면서 세 추정의 비교 시점이다. 1층 야외·증축부 등 지도 시작점이 아직 기준 노드와 연결되지 않은 특수 경로는 원시 보정 수집만 하며, 필요하면 화면의 실제 위치 라벨로 별도 기록한다.
