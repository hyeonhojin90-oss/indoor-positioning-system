# 실내 지도 작업 지침

## 구조 기준

- 3D 작업은 확정된 2D 작업물을 기준으로 한다.
- 코어, 엘리베이터, 메인계단과 좌우 계단 축은 임의로 이동하지 않는다.
- 코어와 강의실 사이에 의도하지 않은 빈 공간이나 겹침을 만들지 않는다.
- 강의실 위치·이름·크기는 층별 자료에 맞춰 조정하되 복도를 막지 않는다.
- 6~10층 오른쪽 끝은 통로를 통해 하나의 강의실·회실로 이어지는 구조다.

## 근거 우선순위

1. GLB·LiDAR 구조
2. Polycam 공간 보고서와 실측
3. 현장 사진과 사용자 설명
4. 피난안내도의 호실 순서와 비례

- 피난안내도만으로 구조 치수를 임의 확정하지 않는다.
- 사용자가 방 순서·크기를 알려줘도 피난안내도와 교차검증한다.
- 스캔에 없는 영역은 벽이나 열린 공간으로 추정하지 말고 미확인으로 기록한다.

## 검증

- 수정 후 대상 층 단독 화면과 통합 화면을 모두 확인한다.
- 2D·3D에서 강의실 끝선, 코어 침범, 빈 공간, 복도 차단을 점검한다.
- 브라우저 콘솔 오류와 데이터·CSS·GLB 404를 확인한다.
