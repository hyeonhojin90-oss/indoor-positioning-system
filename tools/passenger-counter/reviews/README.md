# 개발 영상 통과 장면 부분 검토

`green-bottom-bridge-identity.jsonl`은 문부터 전체 실행한 IN5의 인물·기존 시각 구간 대조다(부분5/6). 백팩181은 상반신 연결의 이벤트이므로 실제 발 위치 복원·정확한 경계 시각까지 검증하지 않는다. `green-reid-bridge-identity.jsonl`은 고정 문 새 사람 추론의4건을 대조했다(부분4/6). 갈색 셔츠와 청록색은 미대응이며 `event-review.jpg`에 원시/집계 박스를 함께 남겼다. 중복 올리브 이벤트는 이번 실행에 없다. 보정에 사용한 city/pink는 현재 개발 자료이며 최초 고정 설정 평가와 구분한다.

후속 `green-penetration-identity.jsonl`은 가로 진입 확인을 적용한 저장 로그 재생의 frame61/267/335/355를 인물별 대조한 목록이다. 청록색은 이제 기존 frame255~315 범위 안이며 네 이벤트 모두 대응한다. 증거는 `runs/green-doorway-full-20260930/penetration-review.jpg`다. 새 전체 모델 추론으로 취급하지 않는다. 부분6명 중 갈색 상의·백팩2명은 여전히 미대응이다.

새 장면 두 편은 개발 설정을 선택한 뒤 원본 표본을 보기 전에 설정 SHA256을 고정했다. `pink-31337217-heldout-manifest.json`, `city-36462986-heldout-manifest.json`에 원본/파생 해시·설정 해시와 검토 순서를 기록했다. 부분 시각 범위는 모델 이벤트를 정답으로 복사한 값이 아니며 단일 검토자 판단이다. 두 영상 결과에 맞춰 통과선·모델·추적 설정을 바꾸지 않는다.

`pink-development-independent-windows.jsonl`은 하차3명의 넓은 구간이다. 원본 frame60 갈색 셔츠의 도로 착지, frame90~110 민트색 상의 하차, frame120~140 체크 셔츠 하차를 대조했다. 앞 교통안내자의 가림 때문에 정확한 한 프레임을 지정하지 않으며 마지막 분홍색 상의의 진행 중 하차는 제외한다. `city-independent-windows.jsonl`은 가운데 출입구의 빨간 외투 승차, 분홍 모자 아이·흰 쇼핑백 회색 외투 하차를 기록한 부분 목록이다. 다른 문과 가려진 승객 전체의 정답은 아니다. `middle-door-review.jpg`는 해당 원본 영역을 확대했으며 검출 박스는 없다. 여러 문 중 현재 프로그램은 하나만 잠그므로 문 선택과 실제 검토 출입구도 함께 대조해야 한다.

2차원 판정 후보의 전체 실행 인물 검토는 `green-doorway-identity.jsonl`에 있다. frame61 올리브색 상의, frame335 노란 가방, frame345 흰 셔츠는 기존 시각 범위 안에 대응한다. frame229 청록색 상의는 해당 인물임을 볼 수 있지만 발이 가려지고 기존 검토 범위(frame255~315)보다 빨라 `uncertain`으로 남겼다. 모델에 맞춰 정답 시각 범위를 옮기지 않았다. 결과는 부분 대응3/6, 미분류 예측1건이며 전체 인원 정확도·precision으로 사용하지 않는다.

2026-09-30 초록색 버스 원본 프레임을 15프레임 간격으로 전체 확인하고 frame45~415를 10프레임 간격으로 추가 확인했다. 모델 박스가 없는 원본 장면에서 문 앞 접근과 발판 진입이 보이는 여섯 승객을 `green-development-windows.jsonl`에 기록했다. 정확한 한 프레임 대신 발판 진입을 포함하는 보수적인 시각 범위를 사용한다. 이 범위는 모델 이벤트 시각을 정답으로 복사한 값이 아니다.

입력은 `data/regression/bus-green-32245403-720.mp4`, SHA256 `9c4aeaf0ffd93df01dec84874e2519b8dfa72b11eb481dfb6525b0d008a0eca2`, 30fps, 513프레임이다. 증거는 `runs/green-source-review-20260930/`과 `runs/green-detail-review-20260930/`에 있다.

시작부터 이미 문 안쪽에 있는 승객, 검은 원피스 승객의 진행 중 승차, 영상 끝에서 아직 대기하는 승객은 부분 검토 목록에 포함하지 않았다. 이 목록은 전체 인원 정답이 아니며 사람의 독립 재검수도 받지 않았다. 모델이 선택된 개발 영상이므로 새 카메라 정확도로 해석하지 않는다. 중첩 시각 범위의 대조는 일대일 최대 매칭으로 수행하지만 인물 ID 대응까지 입증하지는 않는다. 같은 시각에 여러 승객이 들어가면 이벤트 장면을 함께 확인해야 한다.

`evaluate_events.py --reviewed-windows --tolerance 0`으로 부분 목록을 대조한다. 목록 밖 예측은 오탐으로 단정하지 않고 미분류로 남기며 precision은 산출하지 않는다.

YOLO11m + BoT-SORT의 전체 고정 문 추적 결과는 IN3/OUT0이지만 frame61(ID14)과 frame115(ID4)의 박스는 모두 올리브색 상의 승객이다. 두 번째 이벤트는 중복으로 판정했다. `green-m-botsort-identity.jsonl`에 인물 대조 결과를 기록했고 증거는 `runs/green-m-botsort-20260930/events-review.jpg`에 있다. 시각만 대조하면 frame115를 갈색 상의 승객으로 잘못 대응하므로 `--identity-review reviews/green-m-botsort-identity.jsonl`을 함께 사용한다. 인물 검토 결과를 지정하면 검토되지 않은 이벤트는 매칭에 사용하지 않는다. 이 검토는 단일 검토자의 개발 영상 판단이며 독립 현장 정확도 검증이 아니다.
