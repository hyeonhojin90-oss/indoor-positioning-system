# 2026-09-30 재개 목표

사용자 지시로 재개한다. 이번 중단 기준은 5시간 사용량 약95%(잔여 약5%)이며 이전90% 기준을 대체한다. 원시 토큰 잔량과 계정 사용량은 다르므로 실제 세션의 rate_limits 기록으로 확인한다. 마지막 이전 실행 결과와 한도는 CHECKPOINT의 과거 기록으로 유지한다.

1순위는 버스 도착 시 문을 자동 취득하고 승하차 인원을 정확히 세는 것이다. 현재 개발 부분 검토는 초록5/6·도시2/3이며 가림과 ID 소실을 우선 개선한다. 독립 촬영·사람 교정 정답·Orin 실측은 미완료다.

장기 목표는 정류장 대기 줄 규모와 버스의 탑승 여유를 결합해 해당 정류장에 도착할 때의 탑승 가능성을 추정하는 것이다. 가려진 긴 줄의 사람 수를 모두 정확히 보았다고 가정하지 않는다. 현재 보이는 사람 수·줄의 길이/밀집 정도·관측 불확실성·실제 승차 흐름은 별개 정보다. 줄에서 지나가는 사람을 누적한 값은 현재 대기 인원과 같지 않다. 버스 수용 인원·시작 재실 인원·하차 인원·앞 정류장 수요 등이 없으면 탑승 가능성을 확률로 확정할 수 없다. 현재는 참고 설계 목표이며 대기 줄 또는 확률 기능 구현을 우선순위에 추가하지 않는다.

현재 작업: 누락 승객의 원본/트랙 구간 진단 → 여러 검출·추적 방법의 통제 비교 → 전체 영상·부정 사례 회귀 → 인물/시각 검토 → 결과/재개 기록.
